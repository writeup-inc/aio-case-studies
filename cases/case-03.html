受注 コンサルティング 東京都 従業員 1〜5名 AIOマスター

「誰に相談すればいい？」までAIに聞く時代。
事業承継コンサルが"相談先として薦められる"ためにAIOを選ぶまで

東京都の経営コンサルタント（代表1名・2026年設立）。中小企業の事業承継や後継者育成を支援してきた実績はあるが、新しく立ち上げるオンライン講座の集客はゼロからのスタート。SNSもほぼ未経験だった。

3行でわかるこの事例

どんな課題

経営者を相手にする仕事で「知ってもらう」「信用してもらう」の両方が壁。オンライン講座のリリースは1か月後なのに、集客の入口がない。

どう刺さった

ChatGPTに事業承継の悩みを相談し、そのまま「誰に相談すればいいか」まで聞く流れを実演。AIが専門家を推薦する場面を見せ、「ここに選択肢として出てくると強い」と伝えた。

決め手

SNSで毎日テキストを発信すること自体が、AIに拾われる材料になる。SNS施策とAIOを1本の流れとして提案し、追加費用なしで組み込んだ。

会社プロフィール

所在地東京都
事業内容中小企業（売上1億〜3億円規模）向けの経営コンサル。事業承継・後継者育成（後継者塾）、戦略・資金調達・マーケティングの支援
会社規模代表1名（海外拠点と行き来しながら活動）
商談相手代表
集客の現状これまでは人脈・紹介とスポット案件。オンライン講座を約1か月後にリリース予定だが、集客はこれから。SNSはほぼ未経験。AIは主にアイデア出しに使用（投稿文を作らせると「ありきたり」になる）

どんな課題に、AIOマスターがどう刺さったか

左がお客様の課題、右がAIOマスターがその課題の答えとして受け止められた理由です。

課題 1経営者が相手なので「知ってもらう」「信用してもらう」の両方のハードルが高い。
→
刺さった理由経営者はAIに壁打ちしたあと「誰に相談すればいい？」まで聞く。そこで専門家として推薦されれば、第三者の推薦という形で信用ごと届く。3回目 11:30〜11:33
課題 2フォロワーゼロからのSNSで、発信しても見てもらえない。
→
刺さった理由AIに拾われやすいのは、インターネット上のテキスト情報。X・Threadsで毎日テキストを発信すること自体がAIOの対策になる、と説明。SNSを続ける意味が増えた。3回目 11:34〜11:35
課題 3事業承継の支援は、公的機関や同業も発信していて差別化が難しい。
→
刺さった理由AIは悩みの中身に合わせて専門家を選ぶ。「後継者育成」「事業承継」の実績を発信し、その文脈で選ばれる位置を取りにいく。2回目・3回目
課題 4自分のクライアントにも、これからの集客の考え方を伝えられるようになりたい。
→
刺さった理由代表自身が「通常の中小企業にとっても、その分野で検索したときに上に出てくるのは必要になる」と、自分の支援先にも使える視点として受け止めた。3回目 11:35

AIOマスターをどう説明したか（実際の会話）

初回と2回目はSNS集客と、代表自身のAI活用の学び方が中心でした。AIOは最終回で「SNS発信の意味を広げるもの」として加えています。経営者が実際にやっている行動（AIへの壁打ち）を実演し、その先に相談先の推薦があることを見せる順番でした。

3回目商談担当営業と代表／約70分
11:30SNSの提案のあと、「もう1つ重要な点」として切り出す
担当営業少し概念的な話になるかもしれないんですが、ちょっと実演させてください。（ChatGPTを開く）例えば事業承継をテーマに、社長さんが壁打ちするとします。
11:31実演：悩みの相談から「誰に相談するか」へ
担当営業借入が多いとか、何回かやり取りを繰り返していくと、「じゃあ専門家に相談したい」となりますよね。すると、ChatGPTが専門のコンサルタントをピックアップして教えてくれるんです。
担当営業悩みやふとしたきっかけでChatGPTに壁打ちしたあと、そのまま「誰に相談したらいいの？」までが一連の流れでできてしまう。ここに選択肢として出てくるようになると、めちゃめちゃ強い。これをAIO対策といいます。
★ 受注の流れに乗った瞬間経営者が実際にやっている行動（AIへの壁打ち）から、相談先として推薦される場面までを一続きで見せた。
11:34SNSとのつながり
担当営業AIOで出やすくなるのは、インターネット上のテキスト情報なんです。だから、SNSでテキストを発信していくことが、そのまま対策として必要になってきます。
代表これは通常の中小企業にとっても、その分野で検索したときに上に出てくるっていうのは必要になってきますよね。
担当営業そうですね。
ポイント代表は「自分の集客」だけでなく「自分のクライアントにも必要なこと」として受け止めた。コンサル業ならではの刺さり方。
11:57申込書を見ながら
代表SNSの月額の上に、このAIのパッケージ（月額）っていうのは、プラスでかかるんですか。
担当営業かかりません。
ポイントAIOを別料金で売らず、SNS施策と一体の「入口づくり」として組み込んだ。

2回目までに話していたこと

初回・2回目では、AIOの話はほとんど出ていません。集客の入口（X・Threadsで見込み客の母数を作る）と、代表自身がAIを使えるようになるための学び方（研修と、マンツーマンの家庭教師型）が中心でした。

AIOは最終回で、SNSで発信する意味をもう1段広げるものとして加え、その場で申込みに進んでいます。

提案の流れ（この順番で話した）

初回商談
10:03〜10:30温度：中

1. 事業の整理：一番の壁は集客

前職の経験を土台に、中小企業の社長向けコンサルとオンライン講座を立ち上げる段階。代表から「経営者に知ってもらい、信用してもらうハードルを越えるのが大変」という本音が出た。
10:30〜10:55温度：中

2. 入口はSNS（X・Threads）で見込み客の母数を作る

同業のフォロワーに直接アプローチする方法や、Threadsで小さなアカウントが話題になった例を紹介。YouTubeは時間と費用がかかるため、まずは最小限から始める方針を示した。
2回目商談
11:00〜11:30温度：中

3. 提案書で整理：誰に、どこで、どこまで自動化するか

後継者塾の受講者は30〜40代が中心。「AIで作った投稿はありきたりになる」という代表の不安には、人の言葉も混ぜて投稿する設計で応えた。
11:30〜12:00温度：高

4. 代表自身もAIを使えるようになりたい

代表から「自分のクライアントにも、AIで仕組みを作る入口を教えられるようになりたい」という要望。学び方を研修と家庭教師型の組み合わせで提案した。判断は9月中旬に。
3回目商談
11:00〜11:30温度：中

5. 提案内容と契約条件の確認

1年間の伴走で、2年目以降は自分で回せる状態を目指すこと、途中解約の条件などを確認した。
11:30〜11:35温度：高
★ 受注の流れに乗った瞬間

6. ChatGPTでの壁打ちを実演→AIO

悩みの相談から相談先の推薦までを実演し、SNSのテキスト発信がAIに拾われる材料になることを説明（会話は上を参照）。
11:53〜12:21受注

7. SNS施策にAIOを組み込み、その場で申込

AIOは追加費用なしでSNS施策に組み込み、申込書を一緒に確認しながらその場で申込みとなった。

  2. ここに選択肢として出てくるようになると、めちゃめちゃ強い。AIOの価値を一言で

  4. AIに全部任せるより、人の言葉も混ぜたほうが面白い。2回目。投稿の精度への不安に対して

出てきた不安と切り返し

お客様の不安切り返し
AIで作る投稿は「ありきたり」で埋もれるのではAIが人を完全に再現するのは無理と正直に伝え、後継者塾で感じたことなど、本人の言葉を混ぜて投稿する設計にした。
途中で合わなかったら、解約できるのか最低契約は12か月。ツールを売るのではなく、1年伴走しながら試行錯誤する前提と説明した。
海外にいる期間が長い打ち合わせはオンライン、連絡は電話中心でも進められる形にした。

同じ業界でAIOを提案するときのポイント

  1. 経営者・専門家が相手の業種は「AIへの壁打ち→相談先の推薦」の流れを実演する。
  2. SNS施策と一緒に提案するときは「テキスト発信＝AIに拾われる材料」とつなぐ。SNSを続ける理由が1つ増える。
  3. コンサル・士業には「自分のクライアントにも必要になる」視点が刺さる。
  4. AIOを別料金で上乗せせず、入口づくりの一部として組み込むと決めやすい。
